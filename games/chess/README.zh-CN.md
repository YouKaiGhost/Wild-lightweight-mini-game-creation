# 国际象棋，本地版

- **状态：** 可玩 · v0.1
- **语言：** HTML、CSS、JavaScript
- **引擎 / 运行时：** 浏览器；无构建步骤
- **源码：** [`docs/chess-rules.js`](../../docs/chess-rules.js) 和 [`docs/chess.js`](../../docs/chess.js)。可玩版本放在 `docs/`，因为 GitHub Pages 发布的是这个目录。
- **如何运行：** 直接打开 [`docs/chess.html`](../../docs/chess.html)，或者把发布目录跑起来：

  ```bash
  python3 -m http.server 8000 --directory docs
  # 然后打开 http://localhost:8000/chess.html
  ```

- **操作：** 点选棋子，再点高亮格子。方向键移动焦点，Enter 或空格选择/落子。新开一局重置棋盘。
- **规则：** 本地双人国际象棋，白方先行。支持王车易位、吃过路兵、升变（后/车/象/马）、将军、将死和逼和。
- **v0.1 不做：** AI、棋钟、记谱、三次重复、50 回合规则和子力不足和棋。
- **资源与署名：** 无。棋子使用 Unicode 国际象棋字符，棋盘用 CSS 绘制。
- **我学到了什么：** 王车易位是三重检查：王不能一开始就被将军、不能经过被攻击的格子、不能落在被将军的格子。吃过路兵是一个只存在一回合的幽灵格，被吃的兵在目标格旁边。把这两者放进局面对象后，才能跑 perft：初始局面深度 1–4 分别是 20 / 400 / 8,902 / 197,281 个节点。
- **调参：** 棋盘交互在 `docs/chess.js`；走子生成、易位权、吃过路兵、升变和合法走法过滤在 `docs/chess-rules.js`。
