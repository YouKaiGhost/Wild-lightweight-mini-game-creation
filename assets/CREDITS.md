## License reminders

- **CC0 / public domain:** no attribution required, but credit is still polite.
- **CC BY:** attribution is required; include the license name and a link.
- **CC BY-SA:** attribution and share-alike; check that the game's distribution complies.
- **OFL / font licenses:** keep the license text with the font.
- **Commercial or custom licenses:** store the terms and proof of permission in `licenses/`.

If a license requires the full text, put it in `licenses/` and link it from the row above.
