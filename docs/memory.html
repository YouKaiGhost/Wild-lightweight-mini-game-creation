Prototype notes

What this one is teaching me

Two small rules that keep a memory game from feeling broken.

01

Lock the board

Comparing two cards is a state, not a timeout. The board ignores taps while a mismatch is showing. One locked flag prevents the classic third-card bug.

02

Fewer cards

A 4 × 4 board is enough. Eight pairs fit one screen and one sitting; more cards would make the game longer, not deeper.
